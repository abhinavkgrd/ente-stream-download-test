Stream download test

For ente-io/ente#628 — single-ZIP album downloads via a service worker. See README.md for full context, the bugs found on each browser, and how to verify a downloaded file.

Keep-alive vs. idle-timeout

Total 128 MiB in 32 chunks of 4 MiB each, with a 40s pause every 8 chunks (3 pauses). Every byte of a given chunk equals that chunk's own 0-based index mod 256; verify the saved file with verify.mjs (see README).

Firefox Android control (~30s GeckoView threshold)

Isolates just the pause length (keep-alive pings stay on for both) to bracket the ~30s read-timeout found on Firefox for Android — see README for detail. Expect PASS at 25s, FAIL at 35s on that browser specifically; expect PASS at both on every other browser.
